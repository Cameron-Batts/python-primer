# Python Primer

Cameron Batts

Foundational Python exercises covering console output, functions, numeric input, conditionals, loops and basic error handling.

## Files

- hello.py: a short console-output example.
- mini_project.py: an interactive bill-and-tip calculator.

## Run

Use Python 3; no external dependencies are required.

```bash
python3 hello.py
python3 mini_project.py
```

The tip calculator uses 20% for good service, 10% for bad service and 15% for other input. It repeats until you choose to stop. This is a learning exercise; it has not been validated as a production financial application.
